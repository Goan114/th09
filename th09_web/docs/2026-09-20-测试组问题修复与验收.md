## 前端与渲染架构

- 启动器使用本地 TH08／TH10 最终版共用实现：游戏卡片、资源安装／缓存、存档与录像管理、帮助和触控布局。TH09 单独补充房间入口及按住蓄力按钮。
- C++ 游戏经 Emscripten 编译成 Wasm；SDL3 创建渲染环境，实际后端为 WebGL2／GLES3。构建直接链接同一个 `portable/sdl/Renderer.cpp`。
- `GraphicsDevice.hpp` 中 `backend{8,...}` 的 8 是 TH08 的 Alpha 舍入兼容配置，不是 D3D8 版本号。TH10 的特定精度／深度配置并未机械套用于 TH09。
- 运行包不加载原版 EXE、D3D8 DLL、x86 模拟器或测试用原版地址分发。源码中的遗留颜色命名不表示仍调用 Direct3D。
- 标准键盘录像维持原版数据布局；连续触控需要额外移动信息，使用带校验的 THMOTION v2 数据与 `.rpyx` 扩展名。此扩展由本网页版支持，不能承诺 Windows 原版可播放。
- 旧版本在错误 Extra CPU 策略下录制的网页录像未做全面兼容性证明；请保留原文件和产生该录像的旧构建。
