# 花映塚修复候选版源码 · 2026-09-20

此 ZIP 保存 TH09 修改后的 C++、网页适配层、最终版启动器及共享渲染／输入源码，并保留目录相对关系。游戏素材与开发工具不重复打入源码包；完整可运行包另附。

## 布局

- `th09_web/cpp`：游戏与 SDL3 实现。
- `th09_web/sdl-runtime`：浏览器运行层。
- `th09_web/launcher`：GPL-3.0-or-later 最终版启动器源代码及许可证，含本次 TH09 适配。
- `portable/sdl`、`portable/input`：与本工作区 TH08／TH10 共用的源码及第三方许可。
- `th09_web/scripts`、`th09_web/tests`：构建、发布与测试源码。
- `th09_web/verification`：本次通过报告；不包含测试失败中间产物。

## 重建发布版

在原工作区中这些依赖已经齐全。独立解压时按相同布局准备：

1. Node 22+（本次使用 24.15.0），Python，`tools/emsdk` 下的 Emscripten（本次版本串 6.0.9-git，启用 SDL3 与 SDL3_ttf ports）。
2. TypeScript 5.9.3 位于 `tools/architecture/typescript/node_modules/typescript`，这是 `package-launcher.mjs` 当前使用的位置；可通过 npm 向该工具目录安装。
3. 在 `th09_web` 执行 `npm ci` 安装锁定的 ws 依赖。
4. 原版素材可以从本次运行包恢复：`site/th09.dat` 复制到同级 `[th09] 东方花映塚 (日文版)/th09.dat`；`site/fonts/*` 复制到 `th09_web/assets/sdl-native/`；`site/music/*` 复制到 `th09_web/assets/sdl-native/music/`。这些操作是构建前素材准备，不涉及玩家存档。
5. 在 `th09_web` 依次执行：

```powershell
$env:TH09_OUTPUT = 'artifacts/bugfix-20260920/release'
node scripts/build-sdl.mjs --release
node scripts/package-release.mjs
node scripts/package-launcher.mjs
node artifacts/bugfix-20260920/release/scripts/serve.mjs --port 8096
```

前三条构建／打包命令生成 `site` 和服务器；浏览器打开 `http://127.0.0.1:8096/`。`package-release.mjs` 初步复制的快捷脚本沿用开发工作区；独立运行时使用上面的直接服务器命令，或使用另附运行包的自带 Node 启动脚本。

打包脚本含构建路径缓存因素，重新生成的站点构建号不保证逐字相同；最终游戏 Wasm 校验值及源码文件摘要保留在 verification/release-build.json。

## 测试依赖与限制

完整原版对照需要用户已有的日文 1.50a EXE（target.json 指定 SHA-256），原版 EXE 不在此源码 ZIP 中。WASI 比较器使用工作区 `th10_web/tools/wasi-sdk-34.0-x86_64-windows`，Unicorn 测试依赖使用 `th08_web/node_modules/@alexaltea/unicorn-js`。浏览器测试使用工作区 `th10_web/scripts/native/browser-launch.mjs` 及已有 Playwright／浏览器环境。这些仅供开发验证，运行候选包不需要。

`reference/assets` 在此 ZIP 仅包含演示录像和标题参考图；其余完整原版解包结果可沿用开发工作区。不能把本包描述为无需素材和工具即可重跑全部原版对照的独立环境。

本次未解决的实际原版录像偏差，以及物理 Android／iOS 验收范围，详见 `th09_web/docs/2026-09-20-测试组问题修复与验收.md`。
